PChongguo · 全集模式

让 PChongguo 真正能在电脑上把一部剧从头看到尾，而不是只看官网网页版开放的前 5 集。

先说清楚它是怎么做到的

红果官网网页版只是试看：我们实测过，服务端对第 6 集及以后直接拒绝发放播放地址（403 public_fallback_unavailable），改前端、换 cookie 都绕不过。

而手机上红果 App 里全剧本来就是免费的。有一支开源发布的第三方桌面客户端，它自己注册虚拟设备、直接调 App 端接口并解密视频流，所以能在 Windows 上看全 999 集。

全集模式＝把这支免费引擎作为可选组件接到 PChongguo 里。入口、频道页、推广码、收益说明仍然全部是 PChongguo 自己的。

两步开启（只需要做一次安装）

1
安装引擎：打开 PChongguo 文件夹，双击 INSTALL-ENGINE.bat。
它会从上游作者的 GitHub Release 下载官方压缩包并解压到本目录下的 engine\ 文件夹。全程只写 PChongguo 自己的目录，不改系统设置。
2
启动全集模式：双击 START-FULLMODE.bat，或桌面上的 PChongguo-全集 图标（若已生成）。
第一次启动引擎会联网注册设备，请耐心等几秒。之后每次直接双击即可。
3
回到 PChongguo：追剧窗口照常用，推广码与收益说明仍在 免费看全集引导页。

想换频道／看两个码的区别：频道首页　·　看全集引导页

来源、安全与「会不会又帮别人赚钱」

项目说明
引擎来源第三方免费软件 yangbin1322/hongguo-player（GitHub 公开发布的 Windows 版）。不是红果官方产品。
是否打包进 PChongguo没有。我们的 GitHub Release 里只有几十 KB 的网页和脚本，不含任何第三方 exe；引擎由你自己点安装、从上游官方 Release 下载到本机。
会不会给别人带量不会。我们核对过该程序二进制，里面没有任何 invite_code / kol_uid / appId 推广参数，作者也声明完全免费无广告。打开它不会产生别人的拉新归因。
补充：引擎侧栏有一个「打赏作者」按钮，那是自愿打赏，不是自动归因、不看剧也扣不到你任何东西；不点即可。
我自己的收益仍然只走 fullwatch.html 里你自己那张带播放按钮 logo 的推广码。看全集与拿佣金是两件事，别扫官网锁集弹窗里那张纯黑白码。
杀毒软件报毒引擎是未签名程序，火绒 / Defender 可能误删。是否恢复、是否加白名单由你自己决定，PChongguo 不会去改安全软件设置。
会不会突然看不了有可能。上游作者自己也在 README 里写「红果的接口经常调整，旧版本可能突然就播不了」。遇到时重新跑一次 INSTALL-ENGINE.bat 或等上游更新。

两种「看全集」别混在一起

· 全集模式：解决「电脑上把剧看完」，靠第三方 App 端客户端，和收益无关。

· 推广收益：只认「新设备 + 新手机号 + 应用商店装官方 App + App 内绑定你的推广码 + App 内看剧」。电脑上看多久、装多少次播放器都不计入结算。
