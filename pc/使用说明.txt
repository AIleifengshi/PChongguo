PChongguo · 电脑大屏追红果短剧（v4.0 全集模式版）
========================================

【这是什么】
一个独立的电脑追剧窗口。双击打开后直接是红果短剧官网的剧集列表，
点封面 → 点「播放正片」→ 就能在电脑上大屏看剧。
不套壳、不内置网页副本，用的是你电脑自带的 Microsoft Edge。
本版带「频道首页」「看全集引导页」（里面有你自己的推广码），
以及 v4 新增的「全集模式」：电脑上真能把一部剧从头看到尾。

【第一次使用（约 10 秒）】
1. 把整个文件夹解压到桌面或 D 盘等普通目录。
   注意：不要放在 C:\Program Files 下（没有写入权限，登录状态存不住）。
2. 双击 PChongguo.vbs → 直接看到剧集封面墙。
   首次运行会在桌面自动生成三个图标：
     · PChongguo             追剧主程序（打开即剧集封面墙）
     · PChongguo-Full        频道首页：全部分类一键直达 + 免费看全集入口 + 自己的推广码
     · PChongguo-FullSeries  全集模式（需先装可选引擎，见下方）
3. 点一部剧 → 点橙色「播放正片」→ 开始播放。

如果双击 .vbs 没反应，或想手动生成桌面图标：双击 SETUP.bat。
也可以直接双击 channels.html / fullwatch.html / fullmode.html。

【如果弹出「登录发现更多精彩内容」】
这是官网的正常提示，不用登录。点弹窗右上角的 × 关掉即可继续观看。
关掉后视频照常播放，不影响追剧。

【播放小提示】
· 进度条、倍速、清晰度、全屏、选集都在播放器里，和网页版一样。
· 右侧「选集」可跳集；顶部「分类 / 榜单 / 搜索」可找别的剧。
· 登录状态保存在本文件夹的 Profile 里，关掉重开不用重新登录。
· 首次播放若缓冲 1–2 秒属正常。

========================================
【v4 新增 · 全集模式：电脑上把全集看完】
========================================
先说清楚原理（我们逆向核查过，不是猜的）：
红果官网网页版只是「试看」，服务端对第 6 集及以后直接拒绝发放播放地址
（实测换第 12 集的 item_id 会返回 403 public_fallback_unavailable），
改前端、换 cookie 都绕不过 —— 所以只靠官网网页版永远看不了全集。
但红果 App 内全剧本来免费；有一支第三方免费桌面客户端，它自己注册
虚拟设备、调 App 端接口、解密视频流，所以能在 Windows 上看全 999 集。

全集模式 = 把这支免费引擎作为【可选组件】接到 PChongguo 里。
入口、频道页、推广码、收益说明仍然全部是 PChongguo 自己的。

两步开启（安装只需一次）：
  1) 双击 INSTALL-ENGINE.bat
     它会从上游作者的 GitHub Release 下载 Windows 压缩包（约 17 MB），
     解压到本文件夹的 engine\ 子目录。只写本目录，不改系统设置。
  2) 双击 START-FULLMODE.bat 或桌面 PChongguo-FullSeries 图标
     首次启动引擎会联网注册设备，等几秒即可。之后每次直接双击。

关于这支引擎，你需要知道：
  · 来源：第三方免费软件 yangbin1322/hongguo-player（GitHub 公开发布），
    不是红果官方产品；未签名，火绒 / Defender 可能误报，是否加白名单由你决定。
  · 我们的 GitHub Release 里【没有】打包任何第三方 exe，只有几十 KB 的网页和脚本；
    引擎由你自己点安装、从上游官方 Release 下载到本机。
  · 我们核对过它的二进制，里面没有任何 invite_code / kol_uid / appId 推广参数，
    作者也声明完全免费无广告 —— 打开它不会给别人带量、不会产生别人的拉新归因。
  · 上游接口常变（作者自己也在 README 里写「旧版本可能突然就播不了」），
    遇到看不了时重跑 INSTALL-ENGINE.bat 或等上游更新。
  · 它和收益【无关】。你的收益仍然只走 fullwatch.html 里那张带播放按钮 logo 的码。

【频道首页有什么】
双击 PChongguo-Full 或 channels.html 打开，里面有：
  真人剧 / AI剧 / 漫剧 / 漫画 / 热播榜 / 官网首页，一键直达红果官网真实分类，
  以及最醒目的「★ 全集模式」入口（→ fullmode.html）。
点频道在当前窗口打开官网；按 Alt + ← 返回频道页换频道。
每一格都标注「网页试看前 5 集 · 全集在 App」，不骗人。

【重要：为什么没有做一个叫「免费」的频道】（实测）
我们逐部实测过：真人剧 / AI剧 / 漫剧各抽一部，点「播放正片」视频都正常加载，
但点第 12 集时，视频地址不变、第 12 集根本不加载，播放区变成
「扫码进入 App 端，免费看全集」，选集 6–10 全带锁 —— 三部剧结果一字不差，零例外。
官网 90 个分类链接里也没有 free / 免费频道。

那「免费全集」几个字是哪来的？
  · 每部剧网页标题都是「xxx_高清完整版全集免费观看_红果短剧」→ 这是 SEO 标题模板；
  · 官网侧栏写的是「扫码下载安装红果短剧App，App 免费高清看全集」；
  · 手机 App 内才有「选集 · 全60集 · 免费观看」标签。
三处都指 App，不是网页版。所以放一个假的「免费」网页频道是虚假宣传。
v4 的做法是：不造假频道，而是给出真能兑现的「全集模式」。

【看到锁集 / 想拿推广收益】
打开 PChongguo-Full → fullwatch.html，按顺序做：
  1) 先看顶部的「两个码」对比，别扫错：
       官网锁集码：纯黑白、applink.novelquickapp.com、无任何推广参数 → 0 收益；
       你自己的码：中心带播放按钮 logo、kol.fanqieopen.com、带 promotion_code_id → 才有归因。
  2) 用手机扫引导页里「你自己的」mycode.png，按提示从应用商店装官方 App
     并在 App 内完成绑定 —— 这一步才产生推广归因。
  3) 电脑上继续看全集：首选 v4「全集模式」；也可走两条合规路径：
     路径 A（真·电脑端）：装 Windows 安卓模拟器 → 模拟器应用商店装红果
               → App 内扫同一个码 → App 内免费全集，窗口全屏，全程在电脑。
               ⚠ 模拟器属虚拟设备，平台风控可能不结算，收益不保证。
     路径 B（最稳）：手机 App 内看全集 → Win+K 或数据线投屏到电脑大屏。
              归因完全合规，代价是操作在手机、画面在电脑。

  注意：用同一手机号登录官网网页版「不会」解锁网页锁集；官网弹窗里的
  动态唤端码也不含推广参数，本程序不替换、不篡改它。
  「看全集」和「拿收益」是两个独立目标，不要指望扫一次码同时完成。

【为什么以前打不开，现在能了】
旧版本把「推广落地页」当成播放地址，还用了手机标识，官网会强制拦成
「请下载 App」，所以一直是白屏 / 看不到剧。
本版直接打开红果官网网页版，用电脑标识，官网才会给出真正的播放器。
（视频是 H.264，普通浏览器就能播，不需要额外装 HEVC 扩展。）

【环境问题】
· 提示找不到 Microsoft Edge：请安装或修复 Edge（Win10/11 一般已自带）。
· 全集模式下载失败：手动到 github.com/yangbin1322/hongguo-player/releases/latest
  下载 Windows 的 -amd64.zip，把里面所有文件解压到本文件夹的 engine\ 里。
· 想彻底移除：删掉桌面三个 PChongguo 图标和本文件夹即可（engine\ 也在本文件夹内）。
