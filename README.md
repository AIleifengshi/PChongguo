# PChongguo · 电脑大屏追红果短剧

> 双击即用的独立追剧窗口。打开就是剧集封面墙，点一部剧就能在电脑上大屏看。
> 无需安装、无需注册、不套壳、不内置网页副本，整个程序只有几十 KB。

---

## 🚀 三步安装（约 10 秒）

1. 到 [Releases](https://github.com/AIleifengshi/PChongguo/releases) 下载 `PChongguo-PC.zip`。
2. 解压到桌面或 D 盘等普通目录（**不要**放 `C:\Program Files`，那里没有写入权限）。
3. 双击 `PChongguo.vbs` → 直接看到剧集封面墙 → 点一部剧 → 点橙色「播放正片」→ 开始看。

首次运行会自动在桌面生成 `PChongguo` 快捷方式，以后点它就行。
若双击 `.vbs` 没反应，双击 `SETUP.bat` 手动生成快捷方式。

**环境要求**：Windows 10/11 + Microsoft Edge（系统自带）。不需要装 HEVC 扩展，不需要 ffmpeg。

---

## 📺 能看什么

- 打开即为红果短剧官网「真人剧」分类页，顶部可切「漫剧 / AI剧 / 漫画」，还有首页、榜单、搜索。
- 播放页有选集（1–15 / 16–30 …）、进度条、倍速、清晰度、全屏。
- 登录状态保存在程序目录的 `Profile` 里，关掉重开不用重新登录。
- 播放时若弹出「登录发现更多精彩内容」，点右上角 **×** 关掉即可继续观看，**不需要登录**。

## 🔧 为什么旧版一直白屏 / 看不到剧

这是这次修复的核心，如实记录：

| | 旧版（已废弃） | 新版 |
|---|---|---|
| 打开的地址 | `tg.bd.cn` 推广落地页 | `hongguoduanju.com` 红果官网网页版 |
| User-Agent | 手机 iPhone UA | **桌面 UA** |
| 官网反应 | 强制拦成「请下载 App」，不给播放器 | 正常给出播放器和视频流 |
| 程序形态 | 163MB Electron 套壳 + data: URL | 系统 Edge `--app` 独立窗口 |
| 结果 | 白屏、看不到剧 | 实测真实播放（H.264） |

关键结论：**红果官网 H5 只对桌面 UA 开放播放**，手机 UA 会被导向 App 下载。
另外那个推广落地页本质是「任推邦」的拉新页，从来就不是播放页，拿它当播放地址必然看不到剧。

> 实测记录：点击「播放正片」后 `video.src` 为红果官方 CDN
> `v3-hgweb.qznovelvod.com`，`readyState=4`、`duration=135.65s`、
> `canPlayType('avc1')='probably'`，关闭登录提示后 `paused=false`、
> `currentTime` 正常推进并渲染出剧集画面。

## 🔗 关于你自己的链接

- **电脑端追剧走官方网页版，不经过任何推广链接** —— 不会给别人带量，也不会产生归因。
- `分享给朋友.html` 里放着你自己的打开链接（`invite_code=0224811`），**仅用于安利朋友**。
- ⚠ 请不要在自己电脑上用这两条链接自点自看：同设备自点无效，且平台会判定异常、可能清零封号。
  真实收益只来自**他人**通过你的链接进入。

## 📁 文件说明

| 文件 | 作用 |
|---|---|
| `PChongguo.vbs` | 主启动器：拉起 Edge 独立窗口，首次运行自建桌面快捷方式 |
| `PChongguo.ico` | 原创图标 |
| `SETUP.bat` | 可选：手动创建桌面快捷方式 |
| `使用说明.txt` | 图文步骤、常见问题、注意事项 |
| `分享给朋友.html` | 中性的推荐文案与你自己的链接 |
| `Profile/` | 运行后自动生成，保存登录状态与缓存 |

## 🛠 从源码打包

CI（`.github/workflows/build.yml`）只做一件事：校验 `pc/` 下的文件并打成 `PChongguo-PC.zip`。
`tools/` 下是生成图标和启动器的脚本，便于复现，普通用户无需关心。
