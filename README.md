# AI类风湿 · 红果短剧推广助手

> 独立品牌 · 原创外观 · 接入你本人官方推广链接赚佣金的桌面推广中枢。
> 本工具仅作推广引流辅助，**佣金结算与归因以红果 / 任推邦官方后台为准**，不承诺任何收益。

---

## 功能

- **iOS / 安卓双渠道**：分别配置 iOS、安卓官方推广链接，各自生成二维码与一键复制。
- **归因可见**：自动识别推广平台（如 `tg.bd.cn`=任推邦），提取并高亮显示「归因邀请码 / invite_code」，链接缺归因参数时红字警告，防止误用他人码。
- **本地收益记录本**：按日期＋金额＋备注记录每日收益，自动累计总额，数据仅存本机浏览器（localStorage）。
- **抖音推广话术**：按你设置的链接 / 关键词，一键生成可复制的抖音标题/评论区话术。
- **完全原创外观**：深色 + 青绿/靛蓝主题，独立品牌「AI类风湿」，不冒充任何平台。

## 使用方式

### 方式一：浏览器直接打开（零安装）
双击 `index.html` 即可在任意现代浏览器中运行。

### 方式二：打包为 Windows .exe（推荐分发）
本地构建（需联网，首次会下载 Electron 运行时）：
```bash
npm install
npm run build
# 产物：dist/AILFF-win32-x64/AILFF.exe（品牌中文名由 CI 在发布会重命名为 AI类风湿.exe）
```
或首次克隆后在 GitHub 上 **Create Release / 手动触发 Actions**，工作流会自动编译 `.exe` 并作为 Release 资源 / 构建产物附件发布（无需本机下载 Electron）。

## 发布到 GitHub

本仓库已按开源发布规范整理，可直接推送：
```bash
git init
git add .
git commit -m "AI类风湿 · 红果短剧推广助手 v1.0.0"
git remote add origin <你的仓库地址>
git push -u origin main
# 之后在 GitHub 的 Actions 页点 Run workflow，或在 Releases 新建发布，自动产出 exe
```

## 首次配置（必做）
打开后进入「设置」：
1. 填入你**本人**在任推邦 / 星推联盟 / 右豹 等官方后台生成的 **iOS 推广链接**（含你的 `invite_code`）。
2. 填入**安卓推广链接**，注意核对渠道参数 `qd` 与官方安卓链接一致。
3. 可填「推广关键词」用于抖音搜索归因。
> ⚠️ 链接必须为你本人的官方推广链接；使用他人链接 = 替别人赚佣金。

## 合规边界
- 必须使用本人官方推广资质，不得内置他人 ID、不得冒充红果品牌。
- 不抓取 / 绕过红果官方客户端与内容分发，仅通过官方链接跳转。
- 真实数据与佣金以官方后台为准。
