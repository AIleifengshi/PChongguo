## 🚀 三步安装

1. 到 [Releases](https://github.com/AIleifengshi/PChongguo/releases) 下载 `PChongguo.exe`（Windows 64 位）。
2. 双击运行，无需安装、无需注册。
3. 点击「打开红果短剧」，大屏追剧开始。

## 💡 使用方式

- **打开红果短剧**：点一下即可在电脑上进入红果短剧，大屏观看。
