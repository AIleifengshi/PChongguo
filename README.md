# PChongguo · 电脑大屏追红果短剧（v3 看全集引导版）

> 双击即用的独立追剧窗口。打开就是剧集封面墙，点一部剧就能在电脑上大屏看。
> 无需安装、无需注册、不套壳、不内置网页副本，整个程序只有几十 KB。
> **v3 新增**：你自己的推广码 + 「看全集」引导页，把锁集后的用户导到官方 App 归因链路。

---

## 🚀 三步安装（约 10 秒）

1. 到 [Releases](https://github.com/AIleifengshi/PChongguo/releases) 下载 `PChongguo-PC.zip`。
2. 解压到桌面或 D 盘等普通目录（**不要**放 `C:\Program Files`，那里没有写入权限）。
3. 双击 `PChongguo.vbs` → 直接看到剧集封面墙 → 点一部剧 → 点橙色「播放正片」→ 开始看。

首次运行会在桌面自动生成**两个**图标：

| 图标 | 作用 |
|---|---|
| `PChongguo` | 追剧主窗口（官网剧集墙） |
| `PChongguo-Full` | 看全集引导页：你自己的推广码 + 电脑端看全集的两条合规路径 |

若双击 `.vbs` 没反应，双击 `SETUP.bat` 手动生成快捷方式；引导页也可以直接双击 `fullwatch.html` 打开。

**环境要求**：Windows 10/11 + Microsoft Edge（系统自带）。不需要 HEVC 扩展，不需要 ffmpeg。

## 🔒 关于「下载 App 才能看全集」（v3 重点）

这是本版要解决的真实问题，先如实说明，不含糊：

| 已实测事实 | 结论 |
|---|---|
| 官网网页版第 6 集起上锁，弹「扫码进入 App 端，免费看全集」 | 网页版**只是试看** |
| 网页端无「看广告 / 登录 / 会员解锁」入口 | 网页端**没有**官方全集解锁路径 |
| 官方**没有 Windows 客户端** | 电脑上没有官方原生全集播放器 |
| 锁集弹窗的码是 `applink.novelquickapp.com` 动态唤端链接，绑定 `video_series_id` / `vid` / `web_id` / `lock_episode`，**不含推广参数** | 不能、也不应把它替换成自己的码 |
| 推广归因只在**手机 App 内**结算：新设备 + 新手机号 + 应用商店下载 App + App 内扫码绑定 + App 内看剧 | 电脑网页播放 / GitHub 下载 / 装机**都不产生收益** |

**所以有个绕不开的死结**：在「纯电脑网页版」这一个载体上，「全集免费看」和「扫码有收益」不可能同时成立，扫完还能回到电脑继续看更不成立。要三者同时成立，只能让官方 App 跑在电脑上，或让手机 App 画面投到电脑大屏。

`fullwatch.html` 里给出两条合规路径：

- **路径 A · Windows 安卓模拟器（真·电脑端闭环）**：模拟器应用商店装红果 → App 内扫自己的码完成绑定 → App 内免费全集，窗口全屏，全程在电脑。
  ⚠ 模拟器属虚拟设备，平台风控**可能判定为非真实新用户而不结算**，收益不保证。
- **路径 B · 手机 App + 投屏（风控最稳）**：手机扫码完成官方归因 → 手机 App 看全集 → `Win + K` 或数据线投屏到电脑大屏。大屏看全集，收益链路一条不缺；代价是操作在手机、画面在电脑。

> 另外：用同一手机号登录官网网页版**不会**解锁网页锁集（已实测），别在这条路上浪费时间。
> 本程序**不破解网页锁、不篡改官网页面、不抓接口、不替换官网动态码** —— 自己的码放在自己的程序里。

## 💰 关于推广码与收益

- `pc/mycode.png` 是**你自己的**官方推广码（由 `PVhongguo.png` 解码还原后重新生成，H 级纠错，带 logo 亦可正常识别）。
- `pc/promo-url.txt` 存着对应链接；要换码，改 `tools/build_qr.py` 里的 `PROMO_URL` 后重新运行即可再生成二维码和链接文本。
- `分享给朋友.html` 主推这条自有码；早期遗留的两条 `tg.bd.cn` 链接归属未确认，已降级折叠标注、**不作主推**，避免误给他人带量。
- ⚠ **不要自己扫自己的码**：同设备 / 同手机号 / 同网络自点无效，可能被平台判异常、清零封号。收益只来自其他真实新用户。
- ⚠ **抖音合规**：公开视频、评论、私信、主页不要出现二维码、网址、GitHub 链接或「发给 AI 就装」这类暗语，属站外引流，会限流或判违规。引导页是本地文件，只在自己电脑打开。
- 是否结算以官方后台为准，**不承诺「必得收益」**。

## 🔧 为什么旧版一直白屏 / 看不到剧

| | 旧版（已废弃） | 现版 |
|---|---|---|
| 打开的地址 | `tg.bd.cn` 推广落地页 | `hongguoduanju.com` 红果官网网页版 |
| User-Agent | 手机 iPhone UA | **桌面 UA** |
| 官网反应 | 强制拦成「请下载 App」，不给播放器 | 正常给出播放器和视频流 |
| 程序形态 | 163MB Electron 套壳 + data: URL | 系统 Edge `--app` 独立窗口 |
| 结果 | 白屏、看不到剧 | 实测真实播放（H.264） |

关键结论：**红果官网 H5 只对桌面 UA 开放播放**；那个推广落地页本质是拉新页，从来不是播放页。

> 实测记录：点击「播放正片」后 `video.src` 为官方 CDN `v3-hgweb.qznovelvod.com`，
> `readyState=4`、`duration=135.65s`、`canPlayType('avc1')='probably'`，
> 关闭登录提示后 `paused=false`、`currentTime` 正常推进并渲染出剧集画面。
