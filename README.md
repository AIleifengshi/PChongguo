# PChongguo · 电脑大屏追红果短剧（v4.0 全集模式版）

> 双击即用的独立追剧窗口。打开就是剧集封面墙，点一部剧就能在电脑上大屏看。
> 无需安装、无需注册、不套壳、不内置网页副本，整个程序只有几十 KB。
> **v4 新增「全集模式」**：接一支第三方免费引擎作为可选组件，电脑上真能把一部剧从头看到尾，
> 不再只限于官网网页版开放的前 5 集。入口、频道页、推广码、收益说明仍全部是 PChongguo 自己的。
> v3.1 的频道首页与「官网码 vs 你的码」对比继续保留。

## 🚀 三步安装（约 10 秒）

1. 到 [Releases](https://github.com/AIleifengshi/PChongguo/releases) 下载 `PChongguo-PC.zip`。
2. 解压到桌面或 D 盘等普通目录（**不要**放 `C:\Program Files`，那里没有写入权限）。
3. 双击 `PChongguo.vbs` → 直接看到剧集封面墙 → 点一部剧 → 点橙色「播放正片」→ 开始看。

首次运行会在桌面自动生成**三个**图标：

| 图标 | 作用 |
|---|---|
| `PChongguo` | 追剧主窗口（官网剧集墙） |
| `PChongguo-Full` | **频道首页**：全部分类一键直达 + 全集模式入口 + 免费看全集引导 + 你自己的推广码 |
| `PChongguo-FullSeries` | **全集模式**：启动可选的免费引擎看全集（需先运行 `INSTALL-ENGINE.bat`） |

若双击 `.vbs` 没反应，双击 `SETUP.bat` 手动生成快捷方式；也可以直接双击 `channels.html`、`fullwatch.html` 或 `fullmode.html`。

**环境要求**：Windows 10/11 + Microsoft Edge（系统自带）。主程序不需要 HEVC 扩展，不需要 ffmpeg；全集模式的引擎自带所需组件。

## 🎬 v4 新增 · 全集模式（电脑上把全集看完）

**先说清楚**：之前我们说「纯电脑网页版不可能看全集」，这个判断**只对红果官网网页版成立**，不适用于自建客户端。我们做了逆向核查：

| 核查项 | 结果 |
|---|---|
| 官网 SSR `seriesDetail` | `episode_cnt: 999`、`accessible_episode_cnt: 5`，`vid_list` **把全 999 集 vid 都发给浏览器了**，前端只 `slice(0,5)` |
| 唯一取流接口 | `POST /api/video/protected/fallback-play-info?aid=8662` + `{"item_id": ...}`，第 1 集返回未加密 H.264 `main_url` |
| 换成第 12 集 vid | **`403 public_fallback_unavailable`** |
| 带 cookie 走真实路径进第 12 集页 | 标题变「第12集」，但请求体仍是第 1 集 vid、`video.src` 仍是第 1 集流，并弹「扫码进入App端」 |
| 第三方能看全集的客户端 | 自己注册虚拟安卓设备、调 App 端接口、解密 `bytevc1 + cenc-aes-ctr` 流，本地代理喂播放器；其数据库里该剧 `episodes` 全 999 集且 `locked:false` |

所以 v4 **不造假频道、也不破解官网**，而是把那支第三方免费引擎作为**可选组件**接进来：

1. 双击 `INSTALL-ENGINE.bat` —— 从上游官方 GitHub Release 下载约 17 MB 的 Windows 包，解压到本目录 `engine\`。只写本目录，不改系统设置。
2. 双击 `START-FULLMODE.bat`（或桌面 `PChongguo-FullSeries`）—— 首次启动联网注册设备，等几秒即可看全集。

详见 `fullmode.html`。边界必须知道：

| 项目 | 说明 |
|---|---|
| 引擎来源 | 第三方免费软件 `yangbin1322/hongguo-player`，**不是红果官方产品**，未签名，杀软可能误报 |
| 是否打进本 Release | **没有。**本仓库 Release 只有几十 KB 网页与脚本，不含任何第三方 exe；由用户自己点安装从上游下载 |
| 会不会给别人带量 | **不会。**已核对其二进制不含 `invite_code` / `kol_uid` / `appId`，作者声明完全免费无广告 |
| 稳定性 | 上游接口常变（作者 README 也写「旧版本可能突然就播不了」），需要重跑安装脚本或等上游更新 |
| 与收益的关系 | **无关。**收益仍只走 `fullwatch.html` 里用户自己的推广码，结算只在官方 App 内闭环 |
| 红线 | 不破解网页锁、不篡改官网页面、不替换官网动态二维码、不伪造登录态、不分发任何剧集文件 |

## 🚫 为什么没有做一个叫「免费」的频道

这是本版最重要的诚实设计，基于实测而非猜测：

| 核查项 | 结果 |
|---|---|
| 官网分类链接 | 90 个，**无 `free` / 免费频道** |
| AI剧 / 漫剧 / 真人剧 各抽一部 | 点「播放正片」视频均正常加载（`readyState=4`，时长 91–173 秒） |
| 点第 12 集 | **视频地址不变、第 12 集不加载**，播放区变「扫码进入App端，免费看全集」，选集 6–10 带锁 |
| 三部剧结果 | 完全一致 → 平台统一策略，与题材无关，**零例外** |

「免费全集」几个字的真实来源：① 每部剧 `<title>` 模板 `xxx_高清完整版全集免费观看_红果短剧`（SEO）；
② 官网侧栏「扫码下载安装红果短剧App…**App**免费高清看全集！」；③ 手机 App 内「选集 · 全60集 · 免费观看」标签。
**三处都指 App，不是网页版。**

所以放一个假的「免费」网页频道，观众装上后发现第 6 集仍锁，属于虚假宣传、砸口碑。
频道首页里的「免费看全集」入口，指向的是**真能兑现**的地方 —— `fullwatch.html`。

## 🔒 关于「下载 App 才能看全集」

| 已实测事实 | 结论 |
|---|---|
| 官网网页版第 6 集起上锁，弹「扫码进入 App 端，免费看全集」 | 网页版**只是试看** |
| 网页端无「看广告 / 登录 / 会员解锁」入口 | 网页端**没有**官方全集解锁路径 |
| 官方**没有 Windows 客户端** | 电脑上没有官方原生全集播放器 |
| 锁集弹窗的码是 `applink.novelquickapp.com` 动态唤端链接，绑定 `video_series_id` / `vid` / `web_id`，**不含推广参数** | 不能、也不应把它替换成自己的码 |
| 推广归因只在**手机 App 内**结算：新设备 + 新手机号 + 应用商店下载 App + App 内扫码绑定 + App 内看剧 | 电脑网页播放 / GitHub 下载 / 装机**都不产生收益** |

**结论修正**：在「纯电脑网页版」这一个载体上，「全集免费看」和「扫码有收益」不可能同时成立 —— 但这是**两个独立目标，可以分开解决**：
「电脑上把剧看完」用 v4 的[全集模式](#-v4-新增--全集模式电脑上把全集看完)或下面的模拟器／投屏路径；
「拿到拉新收益」只走 `fullwatch.html` 第 1 步的推广码链路。不要指望扫一次码同时完成两件事。

`fullwatch.html` 现已包含：

- 顶部「**官网锁集码 vs 你自己的码**」对比（位置 / 外观 / 解出来的链接 / 有无推广参数 / 结果），避免再扫错；
- 自有推广码 `mycode.png`；
- **路径 A · Windows 安卓模拟器（真·电脑端闭环）**：模拟器应用商店装红果 → App 内扫自己的码完成绑定 → App 内免费全集，窗口全屏。⚠ 虚拟设备可能被风控判不结算；
- **路径 B · 手机 App + 投屏（风控最稳）**：手机扫码完成官方归因 → 手机 App 看全集 → `Win + K` 或数据线投屏到电脑大屏；
- 风控、自推自看、抖音合规红线。

> 同一手机号登录官网网页版**不会**解锁网页锁集（已实测）。
> 本程序**不破解网页锁、不篡改官网页面、不抓接口、不替换官网动态码** —— 自己的码放在自己的程序里。

## 💰 关于推广码与收益

- `pc/mycode.png` 是**你自己的**官方推广码（由 `PVhongguo.png` 解码还原后重新生成，H 级纠错，带 logo 亦可正常识别）。
- `pc/promo-url.txt` 存着对应链接；要换码，改 `tools/build_qr.py` 里的 `PROMO_URL` 后重新运行即可。
- `分享给朋友.html` 主推这条自有码；早期 `tg.bd.cn` 两条链接此前已核实**也属你本人**（任推邦），只是分属不同推广平台，本版按要求统一主推 `PVhongguo.png` 那条，历史链接已折叠标注、不作主推。
- ⚠ **不要自己扫自己的码**：同设备 / 同手机号 / 同网络自点无效，可能被平台判异常、清零封号。收益只来自其他真实新用户。
- ⚠ **抖音合规**：公开视频、评论、私信、主页不要出现二维码、网址、GitHub 链接或「发给 AI 就装」这类暗语，属站外引流，会限流或判违规。引导页是本地文件，只在自己电脑打开。
- 🔴 **两个后台的分工（别去错地方查钱）**：**番茄达人中心**（`kol.fanqieopen.com`）是字节官方推广后台，只负责领项目、申请关键词 / 别名、下载素材、**查推广数据**，**不结算、不能提现**；**任推邦**是你的服务商，负责提供登录邀请码，并且**佣金结算与打款统一在任推邦**。所以 `mycode.png` 的链接落在官方域名是正常的（带 `kol_uid` / `invite_uid`），但看收益、查结算、提现要去**任推邦后台**。
- 官方拉新常见两种归因：① 地推码（本项目这张）扫码绑定；② 达人专属**关键词 / 别名**，新用户 App 内搜词观看即归因，发视频后通常还需回填作品链接。以任推邦项目页要求为准，不要混用。
- 是否结算以**任推邦后台**为准，**不承诺「必得收益」**。

## 🔧 为什么旧版一直白屏 / 看不到剧

| | 旧版（已废弃） | 现版 |
|---|---|---|
| 打开的地址 | `tg.bd.cn` 推广落地页 | `hongguoduanju.com` 红果官网网页版 |
| User-Agent | 手机 iPhone UA | **桌面 UA** |
| 官网反应 | 强制拦成「请下载 App」，不给播放器 | 正常给出播放器和视频流 |
| 程序形态 | 163MB Electron 套壳 + data: URL | 系统 Edge `--app` 独立窗口 |
| 结果 | 白屏、看不到剧 | 实测真实播放（H.264） |

关键结论：**红果官网 H5 只对桌面 UA 开放播放**；那个推广落地页本质是拉新页，从来不是播放页。
